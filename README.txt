EBICO - GitHub Pages starter

ساختار پروژه:
- index.html: ساختار اصلی صفحه
- css/style.css: استایل‌ها و طراحی اختصاصی
- js/script.js: کدهای JavaScript اختصاصی
- assets/: تصاویر، آیکون‌ها و فایل‌های رسانه‌ای

نحوه انتشار:
1. فایل‌ها و پوشه‌ها را در ریشه Repository یعنی ebico0.github.io قرار بده.
2. مطمئن شو index.html در ریشه Repository است، نه داخل یک پوشه دیگر.
3. در GitHub Pages تنظیم کن:
   Settings > Pages > Deploy from a branch > main > /(root)
4. بعد از Commit، چند دقیقه برای انتشار صبر کن.

نکته:
Bootstrap RTL از CDN بارگذاری می‌شود؛ برای مشاهده آن اتصال اینترنت لازم است.
